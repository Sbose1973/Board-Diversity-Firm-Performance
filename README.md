# Board Diversity and Firm Performance in Publicly Listed Technology Companies

## MSc Business Analytics Dissertation

This repository contains the Python-based statistical analysis conducted for the dissertation examining the relationship between board diversity and firm performance in publicly listed technology companies.

## Study Overview

- Study period: 2009–2018
- Sample: 20 publicly listed technology companies
- Observations: 200 firm-year observations
- Research design: Longitudinal panel study
- Dependent variable: Return on Assets (ROA)
- Main independent variable: Female Directors (%)
- Control variables: Board Size, Board Independence, Firm Size and Leverage

## Statistical Analysis

The analysis includes:

- Descriptive statistics
- Pearson correlation analysis
- Multiple linear regression
- Variance Inflation Factor (VIF) test
- Breusch–Pagan test for heteroscedasticity
- Shapiro–Wilk normality test
- Durbin–Watson test
- HC3 heteroscedasticity-robust standard errors
- Supporting statistical visualisations

## Repository Files

- `Board_Diversity_Analysis.ipynb` – complete Python analysis and statistical outputs
- `Final_Locked_Technology_Dataset_200_Observations.csv` – dataset used for the analysis
- `python code Html Dissertation.html` – HTML export of the analysis

The analysis was conducted using Python in Jupyter Notebook. Key packages include pandas, NumPy, SciPy, statsmodels and Matplotlib.
